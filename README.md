## Open source

**[IO-Fortran-Library](https://github.com/acbbullock/IO-Fortran-Library)**
[![Latest release](https://img.shields.io/github/v/release/acbbullock/IO-Fortran-Library?label=latest)](https://github.com/acbbullock/IO-Fortran-Library/releases/latest)
<br>A dependency-free Fortran 2018 library for text, CSV, binary and NumPy
`.npy`/`.npz` files, number–text conversion, and a `String` type.

**[Neural-Network-Quantum-States](https://github.com/acbbullock/Neural-Network-Quantum-States)**
[![Latest release](https://img.shields.io/github/v/release/acbbullock/Neural-Network-Quantum-States?label=latest)](https://github.com/acbbullock/Neural-Network-Quantum-States/releases/latest)
<br>A complex restricted Boltzmann machine that learns the ground state of the
transverse-field Ising chain by variational Monte Carlo, in parallel with
coarrays.
